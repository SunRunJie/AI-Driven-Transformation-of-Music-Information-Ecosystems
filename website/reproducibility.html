02 · Run sequence

Rebuild the empirical baseline

Commands assume Python and the dependencies listed in requirements.txt. The repository currently documents Python 3.14 in its primary PowerShell examples.

1. Install the research environment

py -3.14 -m venv .venv .venv\Scripts\Activate.ps1 python -m pip install -r requirements.txt

2. Verify or restore the documented archives

py src\data_collection\download_archived_datasets.py

The downloader verifies each archive against the checksum stored in the source manifest.

3. Run the default empirical pipeline

py -3.14 src\run_pipeline.py

This loads local observed archives, writes provenance audits and aggregate outputs, and leaves structural-break hypotheses explicitly not_testable when repeated data are absent.

4. Regenerate the complete figure set

py -3.14 src\run_complete_analysis.py

5. Use synthetic mode only as a declared method check

py -3.14 src\run_pipeline.py --demo
Do not mix demo output with empirical evidence.

Demo mode writes a separate synthetic time series and exists to exercise structural-break procedures on a known input.

03 · Known constraints

Reproduction is not the same as identification

Rebuilding the reported numbers does not widen their inferential scope. The same evidence boundaries apply after successful reproduction.

C1
Live collection is currently blocked

RYM returned HTTP 403 and AOTY returned a Cloudflare verification page in August 2026. Failures are logged; generated rows never replace unavailable observations.

C2
The RYM snapshot has no stated license

Aggregate findings can be inspected, but raw redistribution needs a separate terms and license check.

C3
Exact environments are not yet locked

Package lower bounds support portability but may permit version drift. A future lockfile or container would strengthen bit-level reproducibility.

C4
The causal dataset does not yet exist here

A dated repeated panel remains necessary to test post-2022 structural change and competing explanations.

Audit the source, not only the summary.

The complete report, provenance manifest, figure inventory, and analysis modules are available in the repository.
