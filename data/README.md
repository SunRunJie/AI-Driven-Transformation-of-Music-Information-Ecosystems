# Data

This directory holds the datasets used in the study. The project follows a
standard three-tier data layout:

```
data/
├── raw/        # Original, unmodified data as collected
├── processed/  # Cleaned and feature-engineered data (generated)
└── external/   # Third-party or reference datasets (optional)
```

## raw/

| File | Source | Description |
|:-----|:-------|:------------|
| `rym_yearly_charts_2000_2026.csv` | RYM | Yearly chart data for 2000-2026 (albums, artists, average ratings, rating counts, genres) |
| `rym_ratings_timeline.csv` | RYM | Daily rating time series for a sample of representative albums (2020-2026) |
| `rym_forum_ai_discussions.csv` | RYM | Forum discussion data on AI-related topics (2023-2026) |
| `aoty_album_ratings.csv` | AOTY | Album-level rating data (10-point scale) |
| `aoty_genre_trends_2010_2026.csv` | AOTY | Genre-level rating trends for 2010-2026 |

## Notes on data provenance

The collection pipeline is implemented in `src/data_collection/`. It follows a
layered strategy: (a) polite requests to public pages, (b) local caching,
and (c) statistically calibrated synthetic generation when a remote source is
unavailable. As a result, some records are synthetic. See
`docs/Research_Notes.md` for details and the limitations discussed in
`docs/Research_Report.md` (Appendix C).

## processed/

Cleaned and feature-engineered outputs are written here by
`src/preprocessing/data_preprocessing.py`. This folder is git-ignored; it is
regenerated by the pipeline.
