# Data Directory

## Provenance Rule

An observation can enter empirical analysis only when its origin is explicit:

- `is_synthetic=False`, or
- `source` is a recognized collector value such as `rym_web`, `aoty_web`, or
  `aoty_text_snapshot`.

Rows marked synthetic, legacy generator outputs, collection-event logs, and
rows with unknown provenance are excluded by `src/data_provenance.py`.

`data/external/source_manifest.csv` records the source URLs, publisher,
license status, archive checksum, sampling limits, and provenance class. The
RYM dataset publisher does not state a license; check redistribution terms
before publishing the raw file.

The five synthetic files now carry `source=synthetic`,
`is_synthetic=True`, and `provenance_status=illustrative_synthetic` on every
row. Their numbers and generated titles are not claims about either platform.

## Processed Outputs

`data/processed/data_provenance_audit.csv` is generated by preprocessing and
records, for each source table:

- total rows;
- empirical rows;
- synthetic rows;
- unclassified rows;
- inclusion status and reason.

`merged_ratings_timeseries.csv` is written only when usable data exist.
Demo mode writes a separate `demo_synthetic_ratings.csv`, preventing a
synthetic benchmark from replacing the empirical output.

Archive integration also writes `cross_platform_exact_matches.csv`,
`observed_genre_summary.csv`, and `observed_archive_summary.json`. Exact
matching uses normalized artist, title, and release year, followed by duplicate
key removal.

## Collection Constraints

The current environment receives an HTTP 403 from the public RYM chart page.
AOTY returns a Cloudflare verification page to both direct requests and an
automated Chrome rendering session. These failures are recorded in collection
logs and are never replaced with generated rows.

A defensible longitudinal extension requires one of the following:

1. platform authorization or an official API/export;
2. a user-exported browser snapshot collected under the site's terms;
3. a third-party dataset with documented sampling, dates, and licensing.

Raw observations should remain immutable. Cleaning and derived variables
belong in `data/processed/`, with the transformation log retained.
